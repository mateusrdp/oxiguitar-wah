# Features and their tests

Everything the wah-wah plugin does, and the tests that check it. The test names are the ones `cargo test` prints. `scripts/test-all.py` fails when a feature here names no test, or names a test that doesn't exist, so a new feature gets its row and its tests in the same pull request (the [Testing](testing.md) page says how to run them).

| Feature | What it does | Tests |
| --- | --- | --- |
| Open and closed wah marks | Tools put a mark on the caret's beat or on the selected beats, in one Undo step, and the mark reads back. | `editor::tests::a_selection_names_the_beats_that_take_a_mark`, `editor::tests::a_mark_and_its_shape_are_written_on_the_beat_and_read_back`, `tests::the_tools_and_the_views_are_the_manifest_s` |
| The mark's editor | Opens on the kind asked for; picking a kind gives its curve, "no wah" none; Q and the drawn curve follow the window's choices and the pointer; Cancel or closing the window changes nothing. | `editor::tests::the_editor_shows_the_form_and_follows_its_choices_and_the_pointer`, `form::tests::a_new_mark_opens_on_the_kind_asked_for_ready_to_apply`, `form::tests::picking_a_kind_gives_its_curve_and_no_wah_gives_none`, `form::tests::a_mark_s_own_shape_is_shown_and_left_alone_until_changed` |
| The pedal's shape | An open mark rocks heel to toe over the first half of its beat and holds, a closed one back; a mark's own drawn shape is kept in order and in range. | `shape::tests::a_kind_s_own_shape_rocks_over_the_first_half_and_holds`, `shape::tests::a_kept_shape_is_read_back_in_order_and_in_range` |
| Marks become one movement | Alternating marks rock the pedal back and forth; between marks the pedal is off; overlapping marks follow the first. | `curve::tests::marks_become_one_curve_and_the_pedal_is_off_between_them`, `curve::tests::without_marks_there_is_no_curve_and_overlapping_marks_follow_the_first` |
| It sounds like a Cry Baby | A band-pass sweeping 450 Hz to 2.2 kHz whose peak narrows at the heel; Q narrows or widens it; stable at every rate and Q. | `wah::tests::the_cry_baby_sweeps_from_450_hz_to_2200_and_its_peak_narrows_at_the_heel`, `wah::tests::a_mark_s_q_narrows_or_widens_the_peak_and_keeps_its_height`, `wah::tests::a_rocking_pedal_stays_stable_at_every_rate_and_q` |
| Only where the score says | The pedal changes a track only while a mark's beat plays; off, the track passes untouched, and it comes in without a click. | `tests::the_pedal_changes_the_track_only_while_a_mark_s_beat_plays`, `wah::tests::off_it_passes_the_track_untouched_and_it_comes_in_without_a_click` |
| The Wah-wah section of the Track tab | Plays or silences a track's marks, sets Heel and Sweep, and Cry Baby sets them back; followed live while playing. | `section::tests::it_shows_a_cry_baby_that_is_on_and_what_can_be_shown`, `section::tests::its_widgets_set_the_pedal_and_cry_baby_sets_it_back`, `tests::a_track_whose_pedal_is_off_passes_untouched_and_follows_the_section_live` |
| The window and the section in Slint | `ui/wah.slint` compiles as OxiGuitar compiles it, with every property and callback the Wah-Wah window and the Wah-wah section use. | `tests::the_slint_file_has_what_the_views_set_and_hear` |
| Saved with the track | Values kept in step and in range; missing or unreadable settings are a Cry Baby that is on. | `settings::tests::values_are_kept_in_step_and_in_range_and_written_as_typed`, `settings::tests::missing_or_unreadable_settings_are_a_cry_baby_that_is_on` |
| Before the amp | An effect ordered before amps and equalizers, like a pedal in front of an amplifier. | `tests::the_manifest_is_valid_for_the_plugin`, `oxiguitar_plugin_checks::the_manifest_matches_the_plugin` |
| Real time | Nothing allocated and no system calls on the audio thread, within its time budget. | `contract::the_pedal_runs_in_real_time` |
| A working plugin file | The `.oxp` file keeps the plugin contract, with this repository's SDK version and with the newest release of OxiGuitar. | `contract::the_plugin_file_keeps_the_contract`, `stage:contract (latest core)` |
