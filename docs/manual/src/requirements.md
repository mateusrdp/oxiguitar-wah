# Requirements and assumptions

## Requirements

- OxiGuitar 0.23.0 or later (plugin interface 1.16). See [the OxiGuitar manual](https://mateusrdp.github.io/oxiguitar/).
- Windows, macOS or Linux.
- A plugin that plays the track.

## Assumptions

- The pedal is a Cry Baby by default. Other pedals need their own settings.
- Curves and Q values live only in the `.oxg` file. If you send the song to someone without that file, they get the open and closed marks and not your curves.
